The `hpx` command line, one page per subcommand, generated from the Typer
application in `src/helia_profiler/cli/` by `tools/docs/extract_cli.py` at
the source tree this site was built from. Each page lists the command's
arguments and options with their types, defaults and help text as
declared in the CLI; the [User guide](../../guide/) explains when to use
which. Flags given on the command line override the same field in a
`--config` file.
