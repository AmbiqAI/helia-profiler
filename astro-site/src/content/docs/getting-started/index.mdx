Three short steps. Each one builds on the previous.

<CardGrid>
  <LinkCard href="install/" title="1. Install">
    <Icon name="download" slot="icon" />

    Get heliaPROFILER, the ARM GCC toolchain, CMake/Ninja, and J-Link onto your machine. NSX is installed with heliaPROFILER.

  </LinkCard>
  <LinkCard href="first-profile/" title="2. First profile">
    <Icon name="rocket" slot="icon" />

    Plug in an Apollo EVB, run one command, see cycle counts.

  </LinkCard>
  <LinkCard href="quickstart/" title="3. Use a config file">
    <Icon name="file-code" slot="icon" />

    Move from one-liners to repeatable YAML configs you can check into git.

  </LinkCard>
</CardGrid>

:::tip[After the basics]
Once you've got a profile in hand, the [User Guide](../guide/configuration/)
is the next stop. It introduces engines, toolchains, transports, memory
placement, and power capture one topic at a time — pick whichever is
relevant to what you want to measure next.
:::
