## Purpose

You have a result bundle and a configuration file. The rest of the site is
organised by task, and this page maps the questions people ask after a
first profile onto the page that answers each one.

## Prerequisites

[First profile](../first-profile/) and [Configure a run](../configure-a-run/)
done.

## Steps

### By what you want to do

| I want to | Go to |
|---|---|
| Understand every file hpx wrote and the units in each column | [Output files](../../guide/output/) |
| Compare two runs and know when a comparison is not fair | [Analysis and comparison](../../guide/analysis-comparison/) |
| See per-layer cost on the model graph | [Model Explorer overlays](../../guide/model-explorer/) |
| Try another engine: heliaAOT, TFLM or ExecuTorch | [Engines](../../guide/engines/) |
| Build with `armclang` or ATfE instead of GCC | [Toolchains](../../guide/toolchains/) |
| Move the arena or the weights to a different memory | [Memory placement](../../guide/memory/) |
| Capture more counters, or counters from the memory and MVE domains | [PMU counters](../../guide/pmu-counters/) |
| Measure power with a Joulescope or an INA228 | [Power measurement](../../guide/power/) |
| Capture over USB CDC or UART instead of RTT | [Capture transports](../../guide/transports/) |
| Run hpx from Python instead of the shell | [Python API](../../reference/api/) |
| Script a batch of runs or wire hpx into CI | [Batch runs from YAML](../../examples/batch-runs/) |
| Understand a failed run or an issue code | [Issue codes](../../reference/issue-codes/) |

### For agents

Every page on this site has a Markdown rendition at its route plus
`index.md`, the whole site is in `llms-full.txt`, and the generated
reference ships as JSON: `reference/api/reference.json`,
`reference/cli/cli.json`, `reference/configuration/schema.json` and
`reference/issue-codes/issues.json`. Start from
[`llms.txt`](../../llms.txt) for the index.
