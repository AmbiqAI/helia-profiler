<Band tone="muted">
  <SectionHeader
    slot="header"
    eyebrow="How a run works"
    title="One command, eight steps"
    description="A profiling run resolves the target, builds and flashes firmware for the engine you picked, captures counters on the device and writes the result bundle."
    href="/helia-profiler/guide/"
    linkLabel="Read the user guide"
  />

  <CardGrid columns={4} equalize class="not-content">
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S01">Resolve platform</CardHeader>
      <CardContent>Validates the board name, resolves the SoC definition, computes the model file hash and populates platform and model metadata.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S02">Prepare engine</CardHeader>
      <CardContent>Instantiates the selected heliaRT, heliaAOT, TFLM or ExecuTorch adapter and calls its prepare method.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S03">Generate firmware</CardHeader>
      <CardContent>Renders Jinja2 templates into a complete NSX application: the build config, the module manifest, the entry point and the PMU capture harness.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S04">Build firmware</CardHeader>
      <CardContent>Runs the NSX build pipeline, then captures binary section sizes and the compiler and CMake versions.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S05">Flash firmware</CardHeader>
      <CardContent>Flashes the built firmware to the target via nsx flash, which uses JLinkExe.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S06">Capture PMU</CardHeader>
      <CardContent>Resets the target, attaches the selected transport reader, parses the HPX protocol and aggregates counter values across iterations.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S07">Capture power</CardHeader>
      <CardContent>Skipped when power is not enabled. Arms the configured power driver, observes the GPIO-gated clean window and computes statistics from samples inside the accepted gate.</CardContent>
    </Card>
    <Card tone="filled">
      <CardHeader titleAs="h3" step="S08">Generate report</CardHeader>
      <CardContent>Writes summary.json, the per-layer results, run metadata and the Model Explorer files.</CardContent>
    </Card>
  </CardGrid>
</Band>

          'Preview channel, experimental: atomiq110_fpga_turbo',
        ]}
      />
      <CardContent>The board identifies the physical EVB and the SoC determines CPU architecture, PMU capabilities and memory layout. Run hpx boards for the live list. Without an explicit board, the profiler targets apollo510_evb.</CardContent>
    </Card>
  </CardGrid>

  <Callout title="Experimental Atomiq110 support" tone="warning">
    HPX support for the Atomiq110 SoC and the `atomiq110_fpga_turbo` board is
    experimental. It is best-effort, is not a release blocker, and may change or
    be removed in any minor release. It is outside the compatibility guarantees
    for production-silicon targets. Its clock rates, cycle counts, latency,
    power and energy measurements describe the FPGA image only and are not
    representative of production silicon.
  </Callout>
