Build, flash, measure and compare models on Ambiq Apollo hardware from one
command. heliaPROFILER runs a model through heliaRT, heliaAOT, a stock TFLM
baseline or the Cortex-M ExecuTorch runtime, and returns a result bundle you
can read, compare and archive.

## What a run produces

A successful run writes a portable result bundle: a machine-readable summary,
per-layer data, provenance for the firmware and toolchain that produced it, any
validity issues the run detected, and a manifest with artifact sizes and
SHA-256 digests. Two bundles can be compared when their measurement conditions
match.
