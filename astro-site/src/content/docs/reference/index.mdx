Reference covers the contracts heliaPROFILER exposes:

- **CLI**: every `hpx` command, its arguments and its options.
- **Configuration**: the schema behind a `ProfileConfig`, field by field.
- **Issue codes**: every validity issue a run can report.
- **[Python API](/helia-profiler/reference/api/helia_profiler/)**: the 85
  published names, badged stable or experimental.
- **Compatibility**: boards against engines and toolchains, with the evidence
  behind each cell.
- **Wire protocol**: the firmware and host contract, for maintainers rather
  than users.

These pages are generated from the source that defines them, so they arrive
with the reference generation work rather than being hand-copied. The Python
API is generated; the rest are not published here yet.
