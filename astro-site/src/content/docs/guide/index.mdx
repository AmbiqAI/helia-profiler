The User guide is organised by what you are doing. Start with a task below, then follow its prerequisites and examples. If
you have not run a profile yet, [Getting started](../getting-started/) is
the shorter path.

## The blocks of a run configuration

Use these configuration blocks to find the guide for your next change.
The generated [configuration reference](../reference/configuration/) lists
all keys and defaults.

| Block | Choose or inspect |
|---|---|
| `model` | [Model format and arena size](models/), [memory placement](memory/) |
| `engine` | [Runtime or ahead-of-time compiler](engines/) |
| `target` | [Board and clock](boards/), [toolchain](toolchains/), [transport](transports/) |
| `profiling` | [Counters and sampling](pmu-counters/) |
| `power` | [Instrument, wiring and measurement window](power/) |
| `output` | [Result files](output/) and [model overlays](model-explorer/) |
| `timeouts`, `build` | [Stage limits and dependency resolution](configuration/) |
