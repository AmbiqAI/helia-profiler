The User guide is organised by what you are doing. Each page opens with the
table that makes its choice, then the mechanics, then what to read next. If
you have not run a profile yet, [Getting started](../getting-started/) is
the shorter path.

## The blocks of a run configuration

Every `hpx.yml` and every `hpx profile` command sets the same eight blocks.
The diagram shows them as the configuration model nests them; each block
links to the page that explains its choices, and the generated
[configuration reference](../reference/configuration/) lists every key.

The same structure as a list, for readers of the Markdown rendition:

- model: path, arena, placement
- engine: runtime and backend
- target: board and capture
  - board
  - toolchain
  - transport
  - clock
  - psram
  - heartbeat
- profiling: counters, iterations
- power: capture
  - driver
  - ina228
- output: files and overlays
- timeouts: stage limits
- build: modules, offline
  - nsx_modules
