The user guide is organised by what you are doing:

- **Set up a run**: engines, models, boards and targets, toolchains, capture
  transports, memory placement.
- **Measure**: PMU counters, power capture, on-device summaries.
- **Read results**: output files, per-layer latency, analysis and comparison,
  Model Explorer overlays.
- **Concepts**: the pipeline, engine adapters, firmware generation, capture and
  field diagnostics.
