title: Examples
description: Complete heliaPROFILER runs with configuration, captured output and how to read the numbers.
---

Each example is one run end to end: what you will learn, the hardware and
wiring, the software prerequisites, the complete configuration file, the
command, the output it produced, and how to read that output.

Every example states what it was validated on, or says plainly that it has not
been reproduced on hardware yet. A compile-only result is never described as
profiled.

The catalogue is being migrated and is not published here yet.
