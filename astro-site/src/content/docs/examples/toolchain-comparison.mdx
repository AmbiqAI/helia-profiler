## Goal

See how much of a cycle count is the compiler's doing. You will learn how to
vary only `target.toolchain`, what `hpx compare` marks as different, and how
to line up per-layer rows to find where a toolchain gains.

## Hardware and wiring

An Apollo510 EVB on its J-Link USB port; no power instrument.

## Software prerequisites

Two or three toolchains installed and on `PATH`: the GNU Arm toolchain
(`gcc`), the Arm Toolchain for Embedded (`atfe`) and, if licensed, Arm
Compiler 6 (`armclang`). [Toolchains](../../guide/toolchains/) has the
install notes and the aliases; `hpx doctor` reports which ones it can see.

## Config file

No new file: pass `--toolchain` on the command line over one of the
checked-in configs, and give each run its own output directory. The
armclang variants exist as files for the two engines:
[`examples/quickstart/hpx_rt_armclang.yml`](https://github.com/AmbiqAI/helia-profiler/blob/main/examples/quickstart/hpx_rt_armclang.yml)
and
[`examples/quickstart/hpx_aot_armclang.yml`](https://github.com/AmbiqAI/helia-profiler/blob/main/examples/quickstart/hpx_aot_armclang.yml).

## Run

```bash
hpx profile --config examples/quickstart/hpx_rt.yml --toolchain gcc  --output-dir results/rt_gcc
hpx profile --config examples/quickstart/hpx_rt.yml --toolchain atfe --output-dir results/rt_atfe
hpx compare results/rt_gcc results/rt_atfe --output-dir results/rt_gcc-vs-atfe
```

Add `--toolchain armclang` for a third run when Arm Compiler 6 is
installed. Keep `--engine`, the board, the counters and the iteration
count identical across runs.

## How to read it

- The toolchain dimension is informative, not blocking: `hpx compare`
  shows every delta and tells you the compiler changed. Per-layer deltas
  stay because the operation sequence is identical.
- Both engines gain the same 5.5% from ATfE on this model, which says the
  gain is in the shared CMSIS-NN kernels rather than in engine code.
- To see where the gain lands, sort `layer_diff.csv` in the compare output
  directory, or line the two per-layer files up:

```bash
paste -d, <(cut -d, -f1,2,7 results/rt_gcc/profile_results.csv) \
          <(cut -d, -f7 results/rt_atfe/profile_results.csv) | head
```

- `link_family` stays `gnu` for ATfE, so the per-region memory rows remain
  comparable; armclang links with `armlink`, and the comparison omits the
  per-region `used` and `free` rows for that pair while keeping the
  section sizes ([Output files](../../guide/output/)).

## Variations

- armclang: run the two armclang configs above, or `--toolchain armclang`;
  the `link_family` note applies.
- Vary the engine as well and you have the six-run grid; compare within a
  toolchain to isolate the engine, within an engine to isolate the
  toolchain ([Compare engines](../engine-comparison/)).
- `--cpu-clock hp` on Apollo510 changes microseconds and, through memory
  timing, cycles; keep the tier fixed across a toolchain comparison
  ([Boards and targets](../../guide/boards/#2-cpu-clock)).
